# HBM

## 1. 技術定位與演進趨勢
> **HBM (High Bandwidth Memory，高頻寬記憶體)** 是透過 3D 矽穿孔（TSV）技術將多層 DRAM 晶片垂直堆疊，並藉由 [[CoWoS]] 先進封裝與 AI 運算晶片（GPU / [[AI ASIC]]）緊密互連的關鍵記憶體節點，負責打破 AI 模型訓練與推論的「記憶體頻寬牆（Memory Wall）」。
> - **核心規格巨變（HBM4 / HBM4E Base Die 轉向台積電）**：
>   - 過去 HBM3 / HBM3E 時代，最底層的 **Base Die（基礎控制裸晶）** 由記憶體廠以自家 DRAM 製程自製。
>   - 進入 **2026–2027 年的 HBM4 與 HBM4E 世代**，JEDEC 標準將通道寬度倍增至 **2,048-bit** 並導入客製化邏輯（Custom HBM），`[官方指引]` 全球三大記憶體廠已全數靠攏 **[[2330 台積電]] 先進邏輯製程（12nm / 3nm）** 代工 Base Die，使台積電進一步掌握 AI 記憶體底座命脈。

## 2. 產業鏈玩家版圖 (Ecosystem Map)
- **規格制定 / 終端主要需求方**：[[NVDA 輝達]]（Rubin 平台搭載 HBM4/HBM4E）、[[AMD 超微]]、四大 CSP 自研 [[AI ASIC]]
- **核心 Base Die 邏輯代工與 CoWoS 封裝樞紐**：[[2330 台積電]] `🟢 利多`（`🏗️ 中長期基本面`）
- **一階三大 HBM 記憶體原廠**：
  - [[000660.KS SK海力士]] `🟢 利多`：`[官方指引]` 穩居輝達 HBM4 最大供應商，Base Die 交由台積電代工，2026H2 送樣 HBM4E、2027 全面量產。
  - [[MU 美光]] `🟢 利多`：`[官方指引]` 2026 全年 HBM 產能售罄；2027 量產之 HBM4E 核心 DRAM 升級至 1γ (EUV)，且 Base Die 全面轉交台積電代工。
  - [[005930.KS 三星電子]] `🟡 中立/觀察`：`[市場傳聞]` 採「自家 4nm + 台積電 3nm」雙軌 Base Die 策略急起直追，爭取輝達與 CSP HBM4E 認證。
- **二階封測與載板受惠股**：[[3711 日月光投控]]、[[2449 京元電子]]、[[3189 景碩]]

## 3. 事件傳導與規格變動紀錄
- **2026-11-24**：收錄 HBM4 / HBM4E 通道倍增至 2,048-bit，帶動 SK海力士、美光、三星三大廠 Base Die 全數導入 [[2330 台積電]] 先進邏輯製程並強化 [[CoWoS]] 綁定效應（來源：[raw](../../raw/2026-11-24_HBM4與HBM4E基礎裸晶Base_Die全面轉向台積電先進製程.md)）。
- **⚠️ 魔鬼代言人風險 (Gate 3)**：若 HBM4E 16 層堆疊良率爬坡緩慢，或韓系廠擴產過快導致 2027 下半年標準型 HBM 報價鬆動，將影響記憶體廠毛利擴張斜率。
