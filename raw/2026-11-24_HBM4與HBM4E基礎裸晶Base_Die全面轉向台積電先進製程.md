# 2026-11-24 HBM4 / HBM4E 世代交替：三大記憶體廠 Base Die（基礎裸晶）全面轉向台積電先進邏輯製程

## 原始新聞重點與數據摘錄
- **消息來源與發布日期**：2026-11-24（綜合 TrendForce、鉅亨網、TechNews 科技新報與財訊產業調查）
- **核心事實與數據**：
  1. **JEDEC HBM4 通道翻倍至 2,048-bit 引發 Base Die 製程革命**：
     - 過去 HBM3 / HBM3E 時代，記憶體堆疊最底層的 **Base Die（基礎控制晶粒）** 多由記憶體廠以自家 DRAM 製程自製。
     - 進入 **HBM4 與 2027 年 HBM4E 世代**，因通道寬度倍增至 **2,048-bit** 且進入客製化（Custom HBM / cHBM）時代，需整合複雜運算與高速控制邏輯，記憶體廠自有 DRAM 製程已無法滿足功耗與面積需求。
  2. **全球三大記憶體廠 Base Die 全數靠攏 [[2330 台積電]]**：
     - **[[000660.KS SK海力士]]**：`[官方指引]` 穩居 [[NVDA 輝達]] HBM4 最大供應商，已將 HBM4 Base Die 交由台積電先進邏輯製程（12nm 並往 3nm 推進）代工，並與台積電 [[CoWoS]] 深度協同；2026 下半年送樣 HBM4E、2027 年全面量產。
     - **[[MU 美光]]**：`[官方指引]` 2026 全年 HBM 產能已提早售罄；HBM4 採 1β 製程搭配自研 Base Die，但已正式確認 **2027 年量產之 HBM4E 核心 DRAM 升級至 1γ (EUV)，且 Base Die 全面改由台積電代工**。
     - **[[005930.KS 三星電子]]**：`[市場傳聞]` 採「自家 4nm + 台積電 3nm」雙軌策略，為爭取輝達與 CSP 客製化 HBM4E 訂單，配合客戶要求開放採用台積電 3 奈米代工 Base Die。
